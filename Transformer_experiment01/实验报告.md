# 概念理解
1. **注意力 attention**
可以理解为权重矩阵，通过loss等参数让模型学习到哪里是重要的

2. **缩放点积注意力**
决定了模型在处理当前词时，应该把多少注意力放在句子的其他词上
$$Attention(Q,K,V)=softmax(\frac{QK^T}{\sqrt{d_k}})V$$

+ Q:提出的问题  K:输入序列的标签  V:已经准备好的内容，在decoder-only中Q、K、V全部来自同一个输入   
+ $QK^T$ 是Q和K点积，用于计算机相似度，得出的矩阵每一个数字，代表了第i个词和第j个词之间的“相似度”或者“关联性”  
+ $d_k$ 是Q和K的特征维度（向量长度），决定了内积计算的“深度”，刚好等于点积结果的方差  
+ 除以$\sqrt{d_k}$ 用于缩放点积。如果不除，当$d_k$较大时，可能出现Q和K的内积计算出很大的数字，经过softmax加权后会两极分化，最大接近1，其他接近0  
+ $softmax(x_i)=\frac{e^x_i}{\sum_{j}e^x_j}$  
softmax函数是一个把“原始打分”转化为“百分比权重”的转换器，它保证了注意力机制可以公平、可导地分配模型的关注度  
+ 例子说明：
  + 输入一个句子，有 10 个词。每个词向量长度是 64。
  + 生成 Q, K, V，它们的形状都是 [10, 64]。
  + $QK^T$ ：[10, 64] 乘 [64, 10]，得到 [10, 10] 的矩阵。（10 个词两两之间的相似度打分）。
  + 缩放：除以 $\sqrt{64}$ ，形状不变。
  + Softmax：对最后一行做 Softmax，变成权重。形状还是 [10, 10]。
  + 乘 V：权重 [10, 10] 乘 [10, 64]，得到最终的输出 [10, 64]。   
  
  拿需求（Q）去跟所有的标签（K）比对打分，把打分缩放后转化成注意力百分比（Softmax），最后按照百分比去把真正的信息（V）揉捏在一起，得出是一个融合了全局上下文信息的新向量

+ 代码
  ```
  # 计算 Q 和 K 的点积
  scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(Q.size(-1))
  # Softmax 得到注意力权重
  attn_weights = torch.softmax(scores, dim=-1)
  # 乘以 V
  output = torch.matmul(attn_weights, V)
  ```
3. **多头自注意力**
+ 多头，就是让模型同时从多个不同的角度（子空间）去观察同一句话
+ 多头自注意力其实就是把缩放点积注意力当成积木，搭出来的一个更大的结构
+ 自（self）在论文 3.2.3 节中提到，在自注意力层中，所有的 Q、K、V 都来自同一个地方（即前一层的输出）。也就是说，序列是在“自己和自己”做注意力计算。
  $$MultiHead(Q,K,V)=Concat(head_1,...,head_h)W^O$$
$$where\,head_i=Attention(Q_iW_i^Q,KW_i^K,VW_i^V)$$
